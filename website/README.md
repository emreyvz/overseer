# Overseer documentation site

The official landing page and technical documentation hub for **Overseer**, built as a fully
static site with [Eleventy](https://www.11ty.dev/) and deployed to GitHub Pages.

- **No runtime framework** and no external requests: static HTML/CSS, one small progressive-
  enhancement script, self-hosted fonts.
- **Data-driven**: models, pipeline stages, features, changelog and more live in `src/_data/`.
  Add an entry and the page updates. Model and example pages are generated by pagination, so a
  new model is one object in `src/_data/models.js`.
- **Markdown docs**: everything under `src/docs/` is a Markdown file with front matter and
  appears in the sidebar automatically, ordered by `order`.
- SEO, `sitemap.xml`, `robots.txt`, Open Graph, semantic HTML, accessible light/dark themes.

## Develop

```bash
cd website
npm install
npm run dev     # local preview with live reload (http://localhost:8080/overseer/)
npm run build   # static build to _site/
```

## Structure

```text
website/
├─ .eleventy.js          # config (pathPrefix, filters, collections)
├─ package.json
└─ src/
   ├─ _data/             # content (site, nav, models, pipeline, features, ...)
   ├─ _includes/
   │  ├─ layouts/        # base, landing, page
   │  └─ partials/       # head (SEO), header, sidebar, footer
   ├─ assets/            # css, js, fonts, images
   ├─ docs/              # Markdown documentation pages
   ├─ models/            # model list + paginated detail
   ├─ examples/          # example list + paginated detail
   └─ *.njk              # top-level pages (features, technology, api, ...)
```

## Add content

| To add a | Edit / create |
| --- | --- |
| Model | an object in `src/_data/models.js` |
| Pipeline stage | an object in `src/_data/pipeline.js` |
| Feature | an entry in `src/_data/features.js` |
| Example | an object in `src/_data/examples.js` |
| Changelog release | an entry in `src/_data/changelog.js` |
| Doc page | a Markdown file in `src/docs/` (with `title`, `order`) |
| Nav item | `src/_data/nav.js` |

## Deploy

`.github/workflows/deploy-docs.yml` builds and deploys on every push to `main` that touches
`website/**`. Set the repository's **Settings → Pages → Source** to **GitHub Actions** once.
The site is served under `/overseer/`; change `pathPrefix` in `.eleventy.js` for a custom domain.
