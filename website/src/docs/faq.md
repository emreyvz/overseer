- **Does it send data to the cloud?** No. All inference runs on the host; Overseer can run fully offline.
- **Can it run without a GPU?** Yes, at reduced throughput. A GPU greatly speeds up depth and super-resolution.
- **Which cameras are supported?** RTSP and ONVIF network cameras, local video files and single images.
- **Is it open source?** Yes, MIT licensed on GitHub.
- **Can I disable models I don't need?** Yes. DETECTION class filters are gated at the detector and persist.
